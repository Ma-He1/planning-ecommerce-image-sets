# 平台与语言规则

## 规则分层

把决策来源分为：

- **平台硬规则**：来自目标平台当前官方资料或用户提供的发布合同。
- **创意指导**：用于提升可读性、转化和品牌一致性的经验。
- **项目选择**：画幅、色板、字体和作品集节奏等本次设计决定。

优先级为：用户明确指定 > 可靠上下文推断 > 通用作品集默认。记录 `decision_source`、`confidence`、核验时间和来源。

平台规则可能随站点、类目和时间变化。规划前查询当前官方资料；无法核验时，把“发布前复核”写入 `hard_rules`，不要把经验写成强制规定。

## 平台类型

### Amazon

- 使用 `platform_type: "amazon"`，在 `platform_name` 中写明站点。
- 先核验目标站点和类目的首图、背景、售卖物、文字、边框、水印和尺寸要求。
- 若当前规则要求白底无文案首图，使用 `first_image_rule: "main_white"`，首图 `text_strategy.mode` 使用 `none`。
- 副图可规划场景、参数、尺寸、细节和卖点，但所有陈述都要有事实依据。

### 国内货架电商

- 使用 `platform_type: "domestic_marketplace"`，写明具体平台。
- 首图角色、画幅和信息密度服从当前类目与店铺模板。
- 卖点文字可以更直接，但每张图仍只承担一个主要任务。

### 社交电商与内容轮播

- 使用 `platform_type: "social_commerce"`，写明具体平台。
- 根据当前内容规格选择移动端友好的画幅、字号和安全区。
- 使用真实动作和生活环境证明用途；连续卡片形成清晰的信息节奏。

### 品牌官网

- 使用 `platform_type: "brand_site"`。
- 按页面组件槽位确定画幅和文案密度。
- 更强调品牌叙事与视觉一致性，但事实边界不变。

### 作品集

- 使用 `platform_type: "portfolio"`。
- 根据商品形态和展示媒介选择一种画幅，并贯穿整套。
- 作品集允许强化审美叙事，但不能伪装成特定平台强制规则。

### 自定义合同

- 使用 `platform_type: "custom"`。
- 把用户提供的尺寸、模板、语言、安全区和交付格式写入 `hard_rules`。

## 语言分层

| 层级 | 策略 |
|---|---|
| 策划说明 | 简体中文 `zh-CN` |
| 生成提示词 | 简体中文 `zh-CN` |
| 图内新增文案 | 用户指定或目标市场语言 |
| 包装、瓶身、铭牌原文 | `preserve_original` |

市场语言只能作为默认推断，用户指定优先。精确文字、多行文字、复杂字符集和法律敏感表述优先使用 `post_layout`。

## 字体与排版

- 根据品牌气质选择字形，不把某一种字体当作全品类默认。
- 先确定标题、数据、说明和角标的层级，再决定字号、对齐和位置。
- 为文字保留安全区，不遮挡商品关键结构。
- 确保目标语言字库完整、字符正确、数字与单位清晰。
