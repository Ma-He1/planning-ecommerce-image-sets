# 中文提示词与生成路由

## 提示词结构

每张图先写一句 `content_message`，再按以下顺序编译中文提示词：

1. **身份锚点**：指定原始产品参考及必须保留的外观、比例、颜色、结构和包装文字。
2. **单一任务**：说明本图要建立印象、解释价值、展示参数、证明用途或呈现细节。
3. **构图**：写明商品位置、画面占比、视角、留白和视觉动线。
4. **人物动作**：适用时写清人物身份、姿态、手部关系、视线和真实使用动作。
5. **场景证据**：让环境、道具、光影或适度效果直接支撑本图任务。
6. **摄影与品牌感**：描述镜头感、景深、主辅光、材质、色彩和情绪。
7. **文字处理**：给出准确文案、字形方向、层级、位置与安全区，或明确生成无字底图。
8. **保真限制**：禁止改变商品、补画未知结构、伪造参数或重写包装原文。

提示词使用可观察的画面语言。把“高级、冲击力、科技感、治愈”等抽象词转换成具体的构图、光线、色彩、材质和字体决策。

## 参考图分配

每个可执行 `shots[]` 都要填写 `reference_inputs`：

```json
[
  {
    "path": "用户提供的原始参考",
    "purpose": "说明该参考约束的商品身份、角度、纹理、包装文字或尺寸证据"
  }
]
```

- 身份图使用最清晰、最完整的原始产品照。
- 局部细节只有在原图真实可见且像素足够时才放大。
- 新场景持续使用原始产品图作为身份参考。
- 新视角需要同视角参考或可靠多视图证据。
- 不相关参考不能用于填充合同；证据不足的页面进入暂缓模块。

## 图内文案策略

### `none`

用于不需要新增文案的页面。提示词明确保留包装原文，画面不增加标题、数字、图标、水印或边框。

### `direct`

只用于极短、容错较高的文字。写明准确内容、位置、层级和禁止出现的其他文字，生成后逐字检查。

### `post_layout`

用于参数、多行卖点、复杂语言和品牌级排版。提示词要求生成无新增文字的底图，并在指定位置保留干净安全区；随后按 `exact_copy` 确定性排版。

## 执行动作

- `reuse`：原图已经满足页面任务。
- `clean_up`：抠图、清洁背景、裁切、轻度修瑕或真实局部放大。
- `reference_generate`：基于原始商品参考生成主视觉、简单布景或低风险场景。
- `scene_composite`：先生成环境或人物底图，再合成准确商品。
- `generate_then_layout`：先生成无字底图，再加入标题、参数线、图标和说明。

## Codex 生成顺序

用户要求成图时，使用内置 `imagegen`：

1. 先完成身份锚点最强的首图。
2. 再完成最能证明核心价值的页面。
3. 确认商品保真和视觉系统后扩展其余页面。
4. 最后统一排版、色彩和套图节奏。

规划完成与图片生成是两个独立状态；只有实际生成并验收的页面才能记为成图完成。
