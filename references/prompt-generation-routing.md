# 中文提示词与生成路由

## 提示词编译结构

每张图先写一句 `content_message`，确认只有一个主要任务，再按下列顺序写 150–250 个汉字的中文提示词：

1. **身份锚点**：说明以哪些原始参考图中的商品为唯一产品依据，必须保留哪些外观、比例、颜色、包装文字和结构。
2. **单一任务**：明确本图是建立品牌印象、解释某个卖点、展示尺寸、证明用途或展示细节。
3. **版式构图**：商品在左/右/中、占画面比例、视角、留白和视觉动线。
4. **人物动作**：人物与商品发生真实、可见、符合用途的动作；不让人物只做无关摆拍。
5. **场景证据**：环境、道具、光影或适度视觉效果直接支撑卖点。
6. **摄影与品牌感**：焦段感、景深、主辅光、材质表现、色彩层级、目标品牌气质。
7. **文字处理**：准确文案、字体方向、层级、位置、安全区或明确不生字。
8. **保真与禁止项**：不得改变产品，不新增未知接口，不伪造参数，不出现错误包装文字、畸形手或无关道具。

提示词应描述可观察画面，不写“高级一点”“有冲击力”这类无执行信息。把抽象调性翻译成色彩、光线、材质、构图和字形。

## 场景如何支撑卖点

- 降噪/专注：人物处在真实通勤或办公环境，背景人群与交通轻度动感虚化，人物周围形成克制安静区；不能据此宣称未经确认的降噪等级。
- 便携：用自然取放、包内收纳、单手拿取或尺度参照证明，不凭空改变商品尺寸。
- 护肤使用感：用质地、涂抹动作、晨晚护理环境或光泽表现；不把视觉水润升级为医疗功效。
- 饮料口感：用冰感、气泡、冷凝水和饮用动作表现清爽；包装标签必须保持原文。
- 服装版型：用正面站姿、走动和面料垂坠表现；只有正面参考时不生成背面、内衬或微观纤维结构。
- 家电解决问题：先展示问题环境，再通过正在使用的产品和可观察结果证明；不伪造功率、覆盖面积或认证。

## 图内文案策略

### `none`

用于白底首图、纯产品图或不需要文案的底图。提示词明确“画面中不出现任何新增文字、数字、图标、水印和边框；包装原文保留”。

### `direct`

仅用于 2–8 个中文字符或很短的英文标题，且生成模型已证明文字可靠。提示词写出精确文字、位置、字形、字号层级和禁止出现的其他文字。生成后逐字核对。

### `post_layout`

用于参数、复杂卖点、繁体字、多行英文、法律敏感表述或品牌级排版。生图提示词必须明确“除包装原文外不生成任何新增文字，仅在指定位置预留干净安全区”。随后用确定性排版添加 `exact_copy`。

## 参考图分配

每个可执行 `shots[]` 必须把引用分配写成非空 `reference_inputs`，不能只在提示词或说明中提到参考图。每项结构固定为 `{"path": "absolute-or-user-supplied-reference", "purpose": "产品身份、角度或细节依据"}`；`path` 和 `purpose` 都不得为空。`purpose` 应具体说明该引用用于身份、角度、纹理、包装文字或尺寸证据。不要把无关参考图全部塞入每个任务。

- 身份图：使用最清晰、最完整的原始产品照。
- 局部细节：只有原图真实可见且像素足够才允许裁切放大。
- 新场景：原始产品图持续作为身份参考；复杂人物交互优先“场景底图＋准确产品合成”。
- 新视角：必须有同视角原图或可靠多视图证据，否则暂缓。

若现有引用不能支持该图所需的商品身份、角度或细节，直接把模块移入 `deferred_modules`；不得用不相关引用凑满合同。

## 生成动作

当前生产路线只使用 Codex 内置 `imagegen` 图像生成/编辑能力。不得接入、配置或调用外部生图与视频 API，也不得把外部服务作为失败后的备用路线。

- `reuse`：原图已经满足任务，仅需要输出或进入版式。
- `clean_up`：抠图、清洁背景、裁切、轻度修瑕或真实局部放大。
- `reference_generate`：商品仍易保持一致的主 KV、简单布景和低风险场景。
- `scene_composite`：先得到人物/环境底图，再把准确商品抠图合成，适合手部交互、包装文字敏感或身份易漂移的场景。
- `generate_then_layout`：先生成无新增文字底图，再用确定性工具加入标题、参数线、图标和说明。

## 生成顺序

1. 先做身份锚点最强的主图或白底图。
2. 再做最能证明核心价值的一张场景图。
3. 确认商品保真和视觉系统稳定后，扩展其余页面。
4. 最后统一排版、色彩和套图节奏。

若用户明确要求真实出图，使用 Codex 内置 `imagegen` 图像生成/编辑能力。若用户要求外部 API，说明该请求超出当前 Skill 的生产边界并停止该外部调用；仍可继续交付策划、中文提示词或使用 Codex 内置能力出图。不可把“规划已完成”当作“图片已生成”。
